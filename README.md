# Luma — AI 游戏陪伴应用

> A Little Light Beside You.

## 1. 项目介绍

Luma 是一款基于 Android 平台开发的 AI 游戏陪伴应用，初期面向《光·遇》游戏场景。

项目目标是打造一个具有长期记忆、情感理解、主动交流能力的 AI 伙伴，让 AI 不只是回答问题，而是能够理解玩家、记住共同经历，并在游戏过程中提供持续陪伴。

核心定位：**AI 陪伴优先，游戏交互辅助。**

## 2. 项目目标

### 核心功能

- AI 自然语言聊天
- 多轮上下文对话
- 长期记忆管理
- 用户偏好记录
- 情绪识别与状态维护
- AI 主动发起交流
- 共同经历记录
- 游戏画面理解
- 基础游戏交互

### 暂缓功能

- 实时三维地图构建
- SLAM 实时定位
- 复杂自动导航
- 大型本地视觉模型
- 游戏进程内存读取

## 3. 技术架构

### Android 客户端

| 技术 | 用途 |
|---|---|
| Kotlin | Android 原生开发 |
| Android Studio | 开发环境 |
| Jetpack Compose | UI 界面 |
| Room / SQLite | 本地数据存储 |
| Retrofit / OkHttp | 网络通信 |
| MediaProjection | 屏幕捕获 |
| ML Kit | OCR 文字识别 |

### 云端服务

| 技术 | 用途 |
|---|---|
| Python | 服务端开发 |
| FastAPI | HTTP API 服务 |
| 大模型 API | AI 对话与理解 |
| PostgreSQL | 后期云端数据存储 |
| SQLite | 初期轻量数据存储 |

## 4. 系统模块

### 4.1 ChatManager

负责 AI 对话管理。

- 发送用户消息
- 接收模型回复
- 管理上下文
- 管理对话历史

### 4.2 MemoryManager

负责长期记忆。

- 用户基本资料
- 用户交流偏好
- 重要聊天记录
- 共同游戏经历
- 游戏人物资料

记忆分为：

1. 短期记忆：最近对话上下文。
2. 中期记忆：近期重要事件。
3. 长期记忆：稳定偏好、重要人物和共同经历。

### 4.3 EmotionManager

负责情感状态管理。

- 当前情绪识别
- 对话语气分析
- 关系状态维护
- 情绪变化记录

### 4.4 ProactiveManager

负责主动交流。

- 事件触发
- 主动话题生成
- 主动交流频率限制
- 用户主动交流设置

### 4.5 GameDataManager

负责游戏数据采集与管理。

- 游戏画面获取
- OCR 文字识别
- 人物视觉识别
- 游戏事件记录
- 游戏交互控制

不依赖游戏进程内存读取。

## 7. 开发原则

1. 优先保证 AI 陪伴体验。
2. 手机端不承担大型 AI 模型推理。
3. 尽可能使用本地轻量处理降低 API 消耗。
4. 各功能模块独立，减少模块之间的耦合。
5. 记忆与对话分离，避免依赖单纯的聊天上下文。
6. 不依赖游戏进程内存数据。
7. 不将导航和自动游戏作为第一阶段目标。
8. 每完成一个模块，都要在真实设备上测试。

## 8. 第一版交付目标：Luma 0.1

第一版只实现：

- Android 原生应用
- AI 聊天
- 多轮上下文
- 聊天记录保存
- 长期记忆
- 基础情绪状态
- AI 性格配置

暂不开发复杂游戏视觉识别和自动导航。

**最终目标：让 Luma 成为一个能够记住玩家、理解情绪、拥有共同经历，并且可以长期陪伴玩家的 AI 伙伴。**
